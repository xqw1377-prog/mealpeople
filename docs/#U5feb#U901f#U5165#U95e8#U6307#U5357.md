# 餐时间日人力成本管控助手 - 快速入门指南

## 欢迎使用！

欢迎使用餐时间日人力成本管控助手！本指南将帮助您快速上手，充分利用系统的各项功能。

---

## 第一步：登录系统

### 1.1 打开小程序
- 扫描小程序二维码或在微信中搜索"餐时间日人力成本管控助手"
- 首次使用会进入登录页面

### 1.2 选择登录方式
系统支持两种登录方式：

**方式一：微信ID登录（推荐）**
- 点击"微信ID登录"按钮
- 授权微信账号
- 自动完成登录

**方式二：手机验证码登录**
- 输入手机号码
- 点击"获取验证码"
- 输入收到的验证码
- 点击"登录"

### 1.3 首次登录
- 首次登录的用户将自动成为**管理员**
- 拥有系统的所有权限
- 可以管理其他用户的角色

---

## 第二步：选择租户

### 2.1 租户选择页面
- 登录后会进入租户选择页面
- 如果是首次使用，需要先创建租户

### 2.2 创建租户（首次使用）
1. 点击"创建租户"按钮
2. 填写租户信息：
   - **租户名称**：例如"海底捞火锅"
   - **行业类型**：例如"餐饮"
   - **联系方式**：管理员手机号
3. 点击"保存"完成创建

### 2.3 选择租户
- 点击租户卡片进入系统
- 系统会记住您的选择
- 下次登录自动进入该租户

---

## 第三步：基础数据配置

在开始使用核心功能之前，需要先配置基础数据。

### 3.1 创建店铺

**操作路径**：首页 → 管理中心 → 店铺管理

1. 点击右上角"+"按钮
2. 填写店铺信息：
   - **店铺名称**：例如"海底捞王府井店"
   - **店铺地址**：详细地址
   - **联系电话**：店铺电话
   - **店经理**：选择店经理（可选）
3. 点击"保存"

**建议**：
- 至少创建1个店铺
- 多店连锁可创建多个店铺
- 店铺名称要清晰易识别

### 3.2 添加员工

**操作路径**：首页 → 管理中心 → 员工管理

**方式一：手动添加**
1. 点击右上角"+"按钮
2. 填写员工信息：
   - **姓名**：员工姓名
   - **工号**：员工工号（可选）
   - **所属店铺**：选择店铺
   - **员工类型**：正式员工/兼职员工
   - **联系方式**：手机号
   - **入职日期**：入职日期
3. 点击"保存"

**方式二：Excel导入（推荐）**
1. 点击"导入"按钮
2. 下载Excel模板
3. 按模板格式填写员工信息
4. 上传填好的Excel文件
5. 系统自动导入

**建议**：
- 员工较多时使用Excel导入
- 区分正式员工和兼职员工
- 保持员工信息准确完整

### 3.3 配置效能标准（重要！）

**操作路径**：首页 → 管理中心 → 效能标准配置

这是系统的核心配置，用于智能排班和成本管控。

1. 选择配置级别：
   - **租户级别**：适用于所有店铺
   - **店铺级别**：针对特定店铺

2. 配置三个营收区间：

**低营收区（例如：0-10000元）**
- 营收下限：0
- 营收上限：10000
- 效能标准：1200（每人每天创造的营收）
- 管理口令：例如"节约成本，精简人员"

**正常营收区（例如：10000-30000元）**
- 营收下限：10000
- 营收上限：30000
- 效能标准：1500
- 管理口令：例如"标准配置，稳定运营"

**高营收区（例如：30000元以上）**
- 营收下限：30000
- 营收上限：999999
- 效能标准：1800
- 管理口令：例如"高效运营，全力以赴"

3. 点击"保存配置"

**建议**：
- 根据实际经营情况设置区间
- 效能标准要合理，不宜过高或过低
- 管理口令要简洁有力，便于记忆

## 第四步：开始使用核心功能

### 4.1 今日运营仪表盘

**操作路径**：首页（底部导航栏第一个）

**功能说明**：
- 查看今日运营数据（排班完成、优秀排班、延期排班、参与人数）
- 查看本月累计数据（营收、成本、成本率、千元贡献、人效、工时）
- 查看智能数据洞察（自动生成改进建议）
- 查看本月排班数据（总排班、完成排班、优秀排班、延期排班）
- 查看智能分析（完成率分析、优秀率分析）

**使用技巧**：
- 点击右上角刷新按钮更新数据
- 每天早上查看今日数据，了解当日目标
- 每周查看本月累计数据，评估整体趋势
- 关注数据洞察，及时调整策略

**注意事项**：
- 如果显示"暂无本月成本数据"，需要先在"成本管控"页面录入数据
- 数据洞察只在统计天数≥7天时显示

### 4.2 营收-效能矩阵管控

这是系统的核心功能，帮助您实现科学排班和成本控制。

#### 4.2.1 排班规划（早班使用）

**操作路径**：首页 → 管理中心 → 排班规划

**使用场景**：每天早班开始前，根据预估营收制定排班计划

**操作步骤**：
1. 选择店铺和日期
2. 输入预估营收（例如：25000元）
3. 系统自动计算：
   - 所属区间：正常营收区
   - 效能标准：1500元/人/日
   - 目标工时：16.67小时
   - 建议人数：2-3人（按8小时/人计算）
4. 查看管理口令和排班建议
5. 根据建议安排人员

**使用技巧**：
- 预估营收要尽量准确
- 参考历史数据和节假日因素
- 考虑天气、活动等特殊情况
- 保存规划记录，便于后续对比

#### 4.2.2 营业调整（午市后使用）

**操作路径**：首页 → 管理中心 → 营业调整

**使用场景**：午市结束后，根据实际情况调整晚市排班

**操作步骤**：
1. 系统自动显示早班规划数据
2. 输入午市后全天营收预估（例如：35000元）
3. 系统自动识别：
   - 标准切换：从"正常营收区"切换到"高营收区"
   - 新的效能标准：1800元/人/日
   - 新的目标工时：19.44小时
   - 调整建议：增加人员或延长工时
4. 根据建议调整晚市排班
5. 保存调整记录

**使用技巧**：
- 午市结束后立即调整
- 关注标准切换提示
- 及时增加或减少人员
- 避免人力浪费或不足

#### 4.2.3 营业复盘（营业结束后使用）

**操作路径**：首页 → 管理中心 → 营业复盘

**使用场景**：每天营业结束后，复盘当日运营情况

**操作步骤**：
1. 系统显示规划数据回顾
2. 输入实际营收（例如：32000元）
3. 输入实际工时（例如：18小时）
4. 系统自动计算：
   - 人均营收：1777.78元/人/日
   - 效能等级：优秀（≥1500元/人/日）
5. 填写复盘备注（例如："晚市客流超预期，人员配置合理"）
6. 保存复盘记录

**使用技巧**：
- 每天必做，养成习惯
- 对比规划与实际，总结经验
- 记录特殊情况，便于分析
- 关注效能等级，持续改进

#### 4.2.4 排班速查表

**操作路径**：首页 → 管理中心 → 排班速查表

**功能说明**：
- 显示效能标准概览
- 营收-工时速查表（快速查询不同营收对应的目标工时）
- 管理口令速查
- 使用说明

**使用技巧**：
- 打印或截图保存，便于随时查看
- 培训新员工时使用
- 快速决策时参考

### 4.3 排班日志管理

**操作路径**：首页 → 排班日志（底部导航栏第二个）

**功能说明**：
- 记录每次排班的执行情况
- 评分和评价排班质量
- 查看排班统计和排行榜
- 筛选和分析排班数据

**操作步骤**：

**创建排班日志**：
1. 点击右上角"+"按钮
2. 填写日志信息：
   - **日期**：排班日期
   - **员工**：选择员工
   - **店铺**：选择店铺
   - **排班类型**：例如"早班服务"
   - **开始时间**：例如"09:00"
   - **结束时间**：例如"17:00"
   - **评分**：0-100分
   - **完成状态**：优秀/良好/正常/待改进
   - **备注**：详细说明
3. 点击"保存"

**查看排班日志**：
- 使用日期筛选：今日/近7天/近30天
- 使用高级筛选：按员工/店铺/完成状态
- 查看统计数据：总数、完成率、优秀率、平均分
- 查看排行榜：按优秀数或平均分排序

**使用技巧**：
- 每次排班后及时记录
- 评分要客观公正
- 备注要详细具体
- 定期查看排行榜，激励员工

### 4.4 成本管控

**查看分析**：

**使用技巧**：
- 每天营业结束后录入数据

- 定期查看趋势分析

**重要提示**：

## 第五步：日常使用流程

### 5.1 每日早班流程

**时间**：每天早班开始前（例如：08:00）

1. **打开小程序** → 首页
2. **查看今日运营数据**，了解昨日情况
3. **进入排班规划**：
   - 选择今天的日期
   - 输入预估营收
   - 查看排班建议
   - 安排人员上班
4. **通知员工**，确认排班

### 5.2 午市后流程

**时间**：午市结束后（例如：14:00）

1. **进入营业调整**
2. **输入午市后全天营收预估**
3. **查看调整建议**：
   - 是否需要增加人员？
   - 是否需要延长工时？
4. **调整晚市排班**
5. **通知相关员工**

### 5.3 营业结束流程

**时间**：每天营业结束后（例如：22:00）

1. **进入营业复盘**：
   - 输入实际营收
   - 输入实际工时
   - 查看效能等级
   - 填写复盘备注
   - 保存记录

2. **进入成本管控**：
   - 录入当日数据
   - 营收、成本、工时、人数
   - 保存数据

3. **记录排班日志**：
   - 为每个员工创建日志
   - 评分和评价
   - 保存记录

4. **查看首页数据**：
   - 刷新数据
   - 查看今日完成情况
   - 查看本月累计数据
   - 阅读数据洞察

### 5.4 每周流程

**时间**：每周一次（例如：周一上午）

1. **查看数据分析**：
   - 核心指标统计
   - 质量指标分析
   - 店铺统计
   - 员工类型统计

2. **查看排班日志排行榜**：
   - 按优秀数排序
   - 按平均分排序
   - 表扬优秀员工
   - 辅导待改进员工

3. **查看成本管控趋势**：
   - 近7天趋势分析
   - 智能优化建议
   - 制定改进计划

4. **调整效能标准**（如需要）：
   - 根据实际情况
   - 优化营收区间
   - 调整效能标准

### 5.5 每月流程

**时间**：每月月初（例如：1号）

1. **查看上月数据**：
   - 首页本月累计数据
   - 成本率、千元贡献、人效
   - 月度评估结果
   - 数据洞察建议

2. **月度总结会议**：
   - 回顾上月目标完成情况
   - 分析存在的问题
   - 表扬优秀员工和店铺
   - 制定本月改进计划

3. **设定本月目标**：
   - 营收目标
   - 成本率目标
   - 千元贡献目标
   - 人效目标

4. **导出数据报表**（如需要）：
   - 导出上月数据
   - 制作分析报告
   - 存档备份

## 常见问题解答

### Q1: 首页显示"暂无本月成本数据"怎么办？

**A**: 这是正常现象，说明您还没有录入本月的成本数据。

**解决方法**：
1. 进入"管理中心" → "成本管控"
2. 点击"录入数据"
3. 填写每日的营收、成本、工时、人数
4. 保存后返回首页刷新
5. 本月累计数据和智能洞察就会显示

**建议**：每天营业结束后录入数据，确保数据连续性。

### Q2: 数据洞察为什么不显示？

**A**: 数据洞察只在统计天数≥7天时显示，确保数据具有代表性。

**解决方法**：
- 持续录入成本数据
- 等待统计天数达到7天
- 7天后数据洞察会自动显示

### Q3: 如何添加新员工？

**A**: 有两种方式：

**方式一：手动添加**
1. 管理中心 → 员工管理
2. 点击右上角"+"
3. 填写员工信息
4. 保存

**方式二：Excel导入（推荐）**
1. 管理中心 → 员工管理
2. 点击"导入"
3. 下载模板
4. 填写员工信息
5. 上传文件

### Q4: 如何修改效能标准？

**A**: 
1. 管理中心 → 效能标准配置

## 附录：术语解释

### 1. 效能标准
每人每天应创造的营收，单位：元/人/日。例如：效能标准1500元/人/日，表示每个员工每天应创造1500元的营收。

### 2. 目标工时
根据预估营收和效能标准计算出的工时，公式：目标工时 = 预估营收 ÷ 效能标准。

### 3. 成本率
人力成本占营收的比例，公式：成本率 = (人力成本 ÷ 营收) × 100%。理想值：≤30%。

### 4. 千元贡献
每投入1000元人力成本创造的营收，公式：千元贡献 = (营收 ÷ 人力成本) × 1000。理想值：≥3000元。

### 5. 人效
每人每天创造的营收，公式：人效 = 营收 ÷ (工时 ÷ 8)。理想值：≥1500元/人/日。

### 6. 完成率
已完成排班占总排班的比例，公式：完成率 = (已完成数 ÷ 总数) × 100%。理想值：≥80%。

### 7. 优秀率
优秀排班占已完成排班的比例，公式：优秀率 = (优秀数 ÷ 已完成数) × 100%。理想值：≥60%。

### 8. 延期率
延期排班占总排班的比例，公式：延期率 = (延期数 ÷ 总数) × 100%。理想值：≤20%。
