# 三易原则优化总结

## 优化目标

基于"三易原则"（容易学、容易做、容易管理）全面优化休假管理系统，提升用户体验和管理效率。

---

## 一、容易学（Easy to Learn）- 新手友好

### 1.1 视觉优化

#### 休假类型可视化
- **图标系统**：每种休假类型配备专属MDI图标
  - 年假：🏖️ 沙滩图标（i-mdi-beach）
  - 病假：🏥 医院图标（i-mdi-hospital-box）
  - 事假：⏰ 时钟图标（i-mdi-account-clock）
  - 其他：⋯ 省略号图标（i-mdi-dots-horizontal）

- **颜色编码**：统一的颜色语言
  - 年假：蓝色系（专业、可靠）
  - 病假：红色系（紧急、重要）
  - 事假：橙色系（提醒、注意）
  - 其他：灰色系（中性、通用）

#### 状态可视化
- **待审批**：橙色 + 时钟图标
- **已批准**：绿色 + 对勾图标
- **已拒绝**：红色 + 叉号图标
- **已取消**：灰色 + 取消图标

### 1.2 信息提示

#### 类型说明
每种休假类型都有详细说明：
```
年假：带薪年假，用于休息和旅游
提示：建议提前3天申请，方便安排工作交接
```

#### 操作引导
- **快速审批技巧**：页面顶部醒目提示
- **表单填写提示**：每个字段都有说明
- **验证提示**：实时反馈，友好的错误信息

### 1.3 友好的日期显示

#### 智能日期格式
- 今天 → "今天"
- 明天 → "明天"
- 其他 → "5月20日 周一"

#### 双重显示
```
5月20日 周一
2025-05-20
```

## 二、容易做（Easy to Do）- 操作简便

### 2.1 简化表单

#### 智能默认值
- 开始日期：自动设置为明天
- 结束日期：自动设置为明天
- 休假类型：默认选择年假（最常用）

#### 自动计算
- **自然日天数**：自动计算总天数
- **工作日天数**：自动排除周末
- **实时更新**：日期变化立即重新计算

### 2.2 快捷操作

#### 日期快捷选择
- 今天
- 明天
- 后天
- 本周剩余
- 下周

一键填充，无需手动选择日期！

#### 快速审批
- **快速批准**：一键批准，无需填写意见
- **快速拒绝**：一键拒绝，无需填写意见
- **详细审批**：需要填写详细意见时使用

#### 审批意见模板
**批准模板**：
- 同意
- 批准，注意工作交接
- 同意，祝早日康复
- 批准，注意安全
- 同意，按时返岗

**拒绝模板**：
- 当前工作繁忙，建议延期
- 人员紧张，暂不批准
- 请提供相关证明材料
- 请重新选择日期
- 请先完成手头工作

### 2.3 智能验证

#### 实时验证
- 日期顺序检查
- 过去日期检查
- 未来日期限制（最多90天）
- 天数限制（最多30天）

#### 友好提示
- ✅ 验证通过：绿色提示
- ⚠️ 警告信息：橙色提示（不阻止提交）
- ❌ 错误信息：红色提示（阻止提交）

示例：
```
⚠️ 当天请假建议提前通知主管
⚠️ 请假3天以上建议提前3天申请
❌ 开始日期不能晚于结束日期
```

### 2.4 批量操作

#### 多选模式
- 长按卡片进入多选模式
- 点击选择框切换选中状态
- 显示已选数量

#### 批量审批
- 批量批准：一次批准多个申请
- 批量拒绝：一次拒绝多个申请
- 确认对话框：防止误操作

#### 信息卡片优化

- 减少重复操作
- 提高审批效率

### 10.2 配置说明

#### 添加新的休假类型

编辑 `src/db/leave-type-config.ts`：

```typescript
export const LEAVE_TYPE_CONFIGS: LeaveTypeConfig[] = [
  // ... 现有配置
  {
    code: 'maternity_leave',        // 数据库代码
    name: '产假',                   // 显示名称
    icon: 'i-mdi-baby-carriage',    // MDI图标
    color: 'text-pink-600',         // 文字颜色
    bgColor: 'bg-pink-50',          // 背景颜色
    description: '女性员工产假',    // 说明
    isPaid: true,                   // 是否带薪
    maxDays: 98,                    // 最大天数
    tips: '需提供医院证明'          // 使用提示
  }
]
```

#### 添加日期快捷选项

```typescript
export const DATE_SHORTCUTS: DateShortcut[] = [
  // ... 现有配置
  {
    label: '下个月',
    getValue: () => {
      const nextMonth = new Date()
      nextMonth.setMonth(nextMonth.getMonth() + 1)
      nextMonth.setDate(1)
      const startDate = nextMonth.toISOString().split('T')[0]
      
      const endDate = new Date(nextMonth)
      endDate.setMonth(endDate.getMonth() + 1)
      endDate.setDate(0)
      
      return {
        startDate,
        endDate: endDate.toISOString().split('T')[0],
        days: endDate.getDate()
      }
    }
  }
]
```
