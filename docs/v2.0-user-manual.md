## 智能营收预测

### 功能说明

智能营收预测功能可以帮助您：
- 预测未来月度或日度营收
- 考虑多种影响因子（天气、节假日、营销活动等）
- 提供保守、基准、乐观三种预测场景
- 追踪预测准确率

### 使用步骤

#### 1. 进入预测页面

首页 → 2.0智能功能 → 智能营收预测

#### 2. 配置预测参数

- **预测类型**：选择"月度预测"或"日度预测"
- **目标时期**：选择要预测的月份或日期
- **店铺选择**：选择要预测的店铺（可选全部店铺）

#### 3. 查看影响因子

系统会自动加载该时期的有效影响因子，包括：
- 天气因素（晴天、雨天、高温等）
- 节假日（春节、国庆、周末等）
- 营销活动（满减、会员日、新品推广等）
- 竞争因素（新店开业、竞品促销等）
- 内部因素（装修升级、服务培训、设备故障等）

#### 4. 执行预测

点击"开始预测"按钮，系统会：
1. 分析历史营收数据
2. 计算影响因子的综合影响
3. 生成三种预测场景
4. 保存预测记录

#### 5. 查看预测结果

预测结果包括：
- **保守预测**：最低可能的营收值
- **基准预测**：最可能的营收值
- **乐观预测**：最高可能的营收值
- **置信度**：预测的可信程度（0-100%）

### 使用示例

**场景**：预测12月份营收

1. 选择"月度预测"
2. 选择"2025-12"
3. 查看影响因子：
   - 春节假期：+50%
   - 满减活动：+25%
   - 雨天：-15%
4. 点击"开始预测"
5. 查看结果：
   - 保守：¥45,000
   - 基准：¥50,000
   - 乐观：¥55,000
   - 置信度：85%

### 管理影响因子

点击"管理影响因子"按钮，可以：
- 添加新的影响因子
- 编辑现有因子的影响值
- 设置因子的生效和过期时间
- 删除不再需要的因子

## 影响因子管理

### 功能说明

影响因子是影响营收的各种外部和内部因素，合理配置影响因子可以提高预测准确率。

### 因子类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 天气 | 天气状况 | 晴天、雨天、高温、寒潮 |
| 节假日 | 法定节假日和周末 | 春节、国庆、周末 |
| 营销活动 | 促销和营销活动 | 满减、会员日、新品推广 |
| 竞争 | 竞争对手动态 | 新店开业、竞品促销 |
| 内部 | 内部运营因素 | 装修升级、服务培训、设备故障 |

### 添加影响因子

#### 1. 进入管理页面

首页 → 2.0智能功能 → 智能营收预测 → 管理影响因子

或

首页 → 2.0智能功能 → 影响因子管理

#### 2. 填写因子信息

- **因子类型**：选择因子类型
- **因子名称**：输入因子名称（如"满减活动"）
- **因子分类**：输入分类（如"促销活动"）
- **影响值**：输入影响值（-1.0到1.0之间）
  - 正值表示增加营收（如0.25表示增加25%）
  - 负值表示减少营收（如-0.15表示减少15%）
- **置信度**：输入置信度（0-1之间，默认1.0）
- **生效日期**：选择因子开始生效的日期
- **过期日期**：选择因子失效的日期（可选）
- **描述**：输入因子的详细说明

#### 3. 保存因子

点击"保存"按钮，因子会立即生效。

### 编辑影响因子

1. 在因子列表中找到要编辑的因子
2. 点击"编辑"按钮
3. 修改因子信息
4. 点击"保存"

### 删除影响因子

1. 在因子列表中找到要删除的因子
2. 点击"删除"按钮
3. 确认删除

### 使用技巧

1. **合理设置影响值**
   - 重大节假日：0.3-0.5
   - 一般促销活动：0.1-0.3
   - 天气影响：-0.2-0.1
   - 竞争影响：-0.2-0

2. **设置过期时间**
   - 临时活动要设置过期时间
   - 长期因素可以不设置过期时间

3. **定期更新**
   - 根据实际效果调整影响值
   - 删除已过期的因子
   - 添加新的影响因素

## 排班优化

### 功能说明

排班优化功能可以帮助您：
- 根据目标营收反推人员需求
- 获取智能排班建议
- 推荐最佳休假时间
- 分析人员效率

### 使用步骤

#### 1. 进入优化页面

首页 → 2.0智能功能 → 排班优化

#### 2. 输入目标营收

- 输入您期望达到的营收目标
- 选择目标日期
- 选择店铺（可选全部店铺）

#### 3. 计算人员需求

点击"计算需求"按钮，系统会：
1. 分析历史人效数据
2. 计算所需员工数量
3. 计算总工时
4. 估算人力成本

#### 4. 查看优化建议

系统会提供：
- **人员配置建议**：每个岗位需要多少人
- **排班方案建议**：具体的排班安排
- **休假推荐**：哪些时段适合安排休假
- **效率提升建议**：如何提高人员效率

#### 5. 应用建议

根据系统建议调整排班计划。

### 使用示例

**场景**：12月目标营收5万元

1. 输入目标营收：50000
2. 选择日期：2025-12-01
3. 点击"计算需求"
4. 查看结果：
   - 需要员工：8人
   - 总工时：64小时
   - 预计成本：¥4,800
   - 人效：0.096

5. 查看建议：
   - 服务员：5人
   - 厨师：2人
   - 收银员：1人

### 休假推荐

系统会分析：
- 历史营收低谷期
- 人员富余时段
- 推荐最佳休假时间

## 风险预警

### 功能说明

风险预警功能实时监控运营风险，包括：
- 人员风险（缺勤、流失）
- 成本风险（人力成本率）
- 排班风险（覆盖率、连续工作）

### 风险级别

| 级别 | 颜色 | 说明 | 处理优先级 |
|------|------|------|-----------|
| 高风险 | 红色 | 严重影响运营 | 立即处理 |
| 中风险 | 橙色 | 需要关注 | 尽快处理 |
| 低风险 | 黄色 | 轻微影响 | 计划处理 |

### 使用步骤

#### 1. 进入预警页面

首页 → 2.0智能功能 → 风险预警

#### 2. 查看风险列表

系统会显示所有检测到的风险，包括：
- 风险标题
- 风险级别
- 风险类型
- 风险描述
- 影响范围
- 预计损失

#### 3. 查看详细信息

点击风险卡片，查看：
- 详细描述
- 影响分析
- 建议措施
- 处理优先级

#### 4. 处理风险

根据建议措施处理风险：
1. 点击"确认"标记为已知晓
2. 采取措施解决问题
3. 点击"解决"标记为已解决
4. 填写解决说明

### 风险类型

#### 人员风险

- **员工缺勤率过高**
  - 触发条件：缺勤率 > 10%
  - 建议措施：联系员工、安排替补

- **员工流失风险**
  - 触发条件：离职率 > 15%
  - 建议措施：改善工作环境、提高待遇

#### 成本风险

- **人力成本率偏高**
  - 触发条件：成本率 > 30%
  - 建议措施：优化排班、提升效率

- **加班成本过高**
  - 触发条件：加班费 > 总成本的20%
  - 建议措施：合理安排排班

#### 排班风险

- **排班覆盖率不足**
  - 触发条件：覆盖率 < 90%
  - 建议措施：增加排班人员

- **连续工作时间过长**
  - 触发条件：连续工作 > 6天
  - 建议措施：安排休息

## 数据分析

### 功能说明

数据分析功能提供：
- 多维度数据分析
- 趋势预测
- 异常检测
- 数据可视化

### 使用步骤

#### 1. 进入分析页面

首页 → 2.0智能功能 → 数据分析

#### 2. 选择分析范围

- 选择店铺（可选全部店铺）
- 选择时间范围（7天、30天、90天）

#### 3. 查看数据概览

系统会显示：
- 总营收
- 总成本
- 平均效能
- 成本率

#### 4. 查看趋势分析

系统会分析：
- 营收趋势
- 成本趋势
- 效能趋势
- 预测未来走势

#### 5. 查看异常检测

系统会标记：
- 异常高的营收
- 异常低的营收
- 异常高的成本
- 异常低的效能

### 分析维度

- **时间维度**：日、周、月
- **店铺维度**：单店、多店、全部店铺
- **指标维度**：营收、成本、效能、人数

## 常见问题

### Q1: 预测不准确怎么办？

**A**: 提高预测准确率的方法：
1. 确保有足够的历史数据（至少3个月）
2. 及时更新影响因子
3. 根据实际情况调整影响值
4. 定期回顾预测准确率

### Q2: 如何设置合理的影响因子？

**A**: 设置影响因子的建议：
1. 从小的影响值开始（如0.1）
2. 观察实际效果后调整
3. 参考历史数据
4. 咨询行业经验

### Q3: 风险预警太多怎么办？

**A**: 管理风险预警的方法：
1. 优先处理高风险
2. 制定处理计划
3. 定期回顾已解决的风险
4. 调整风险阈值

### Q4: 排班建议不合理怎么办？

**A**: 优化排班建议的方法：
1. 检查历史数据是否准确
2. 更新人员效能数据
3. 考虑特殊情况
4. 人工调整后应用

### Q5: 如何导出数据？

**A**: 数据导出功能：
1. 在数据分析页面
2. 点击"导出"按钮
3. 选择导出格式（Excel/PDF）
4. 下载文件

### Q6: 数据安全吗？

**A**: 数据安全保障：
1. 所有数据加密存储
2. 租户数据完全隔离
3. 审计日志记录所有操作
4. 支持数据快照和恢复

### Q7: 如何切换回1.0版本？

**A**: 版本切换：
1. 1.0和2.0功能可以同时使用
2. 在首页可以看到两个版本的功能区
3. 数据互不影响
4. 可以随时切换

### Q8: 遇到问题如何获取帮助？

**A**: 获取帮助的方式：
1. 查看本用户手册
2. 查看快速开始指南
3. 联系技术支持
4. 提交问题反馈
