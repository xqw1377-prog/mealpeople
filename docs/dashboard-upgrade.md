# 首页今日运营仪表盘升级说明

## 版本：v2.26.0
## 日期：2025-11-06

## 概述

本次更新对首页的今日运营仪表盘进行了全面升级，实现了当日数据和本月累计数据的对比展示，并新增了整体状态评估和智能数据洞察功能，帮助管理者更好地了解运营状况和做出决策。

## 主要功能

### 1. 核心指标展示

#### 1.1 营收对比
- **当日营收**：显示今天的营收金额
- **累计营收**：显示本月累计营收金额
- **日均营收**：自动计算本月日均营收

#### 1.2 排休人数对比
- **当日排休**：显示今天的排休人数
- **累计排休**：显示本月累计排休人数
- **日均排休**：自动计算本月日均排休人数

#### 1.3 人效对比
- **当日人效**：营收 ÷ 排班人数（元/人/日）
- **累计人效**：累计营收 ÷ 累计排班人数（元/人/日）
- **状态标签**：根据人效值显示优秀/良好/待提升

**人效评估标准：**
- ≥1500元/人/日：优秀 ✅
- 1000-1500元/人/日：良好 👍
- <1000元/人/日：待提升 ⚠️

#### 1.4 薪酬对比
- **当日薪酬**：显示今天的人力成本
- **累计薪酬**：显示本月累计人力成本
- **日均薪酬**：自动计算本月日均人力成本

#### 1.5 1000元薪酬贡献对比
- **当日贡献**：(当日营收 ÷ 当日薪酬) × 1000
- **累计贡献**：(累计营收 ÷ 累计薪酬) × 1000
- **状态标签**：根据贡献值显示优秀/良好/一般

**千元贡献评估标准：**
- ≥4000元：优秀 ✅
- 3000-4000元：良好 👍
- <3000元：一般 ⚠️

**含义说明：**
每投入1000元薪酬，能够产生多少元的营收。数值越高，说明薪酬的投入产出比越好。

#### 1.6 人力成本占营收比对比
- **当日占比**：(当日薪酬 ÷ 当日营收) × 100%
- **累计占比**：(累计薪酬 ÷ 累计营收) × 100%
- **状态标签**：根据占比显示优秀/良好/偏高

**成本率评估标准：**
- ≤25%：优秀 ✅
- 25%-30%：良好 👍
- >30%：偏高 ⚠️

### 2. 整体状态评估

系统会根据累计数据的三个关键指标（成本率、人效、千元贡献）进行综合评估，给出整体运营状态：

#### 2.1 运营优秀 🎉
**条件：**
- 成本率 ≤ 25%（优秀）
- 人效 ≥ 1500元/人/日（优秀）
- 千元贡献 ≥ 4000元（优秀）

**说明：** 所有核心指标都达到优秀标准，运营状况非常好。

#### 2.2 运营良好 👍
**条件：**
- 成本率 ≤ 30%（优秀或良好）
- 人效 ≥ 1000元/人/日（优秀或良好）
- 千元贡献 ≥ 3000元（优秀或良好）

**说明：** 核心指标都在良好范围内，运营状况稳定。

#### 2.3 需要改进 ⚠️
**条件：**
- 成本率 > 30%（偏高）
- 或 人效 < 1000元/人/日（待提升）

**说明：** 存在需要改进的指标，建议采取优化措施。

#### 2.4 正常运营 ✓
**条件：** 不满足以上任何条件

**说明：** 运营状况正常，但有提升空间。

### 3. 智能数据洞察

当本月累计数据达到3天或以上时，系统会自动分析数据并提供针对性的洞察和建议：

#### 3.1 成本率洞察
- **成本率 > 30%**：
  - 提示：成本率XX%，建议优化排班或提升营收
  - 建议：减少不必要的人力投入，或通过营销活动提升营收

- **成本率 ≤ 25%**：
  - 提示：成本率XX%，成本控制良好，继续保持
  - 鼓励：当前成本控制做得很好，保持这个水平

#### 3.2 人效洞察
- **人效 < 1000元/人/日**：
  - 提示：人效XX元/人/日，建议优化工作流程或加强员工培训
  - 建议：
    - 优化工作流程，提高工作效率
    - 加强员工培训，提升服务质量
    - 合理安排排班，避免人力浪费

- **人效 ≥ 1500元/人/日**：
  - 提示：人效XX元/人/日，人效表现优秀，团队效率高
  - 鼓励：团队效率很高，继续保持

#### 3.3 千元贡献洞察
- **千元贡献 < 3000元**：
  - 提示：千元贡献XX元，可通过提升人效改善
  - 建议：
    - 提高人均产出
    - 优化薪酬结构
    - 提升服务质量以增加营收

## 数据来源

### 数据表
所有数据来源于 `schedule_results` 表，该表记录了每日的排班结果和关键指标。

### 数据计算逻辑

#### 当日数据
- 查询今天日期的排班结果记录
- 直接使用记录中的各项数据

#### 累计数据
- 查询本月1号到今天的所有排班结果记录
- 对各项指标进行求和或平均计算：
  - 营收：求和
  - 排休人数：求和
  - 排班人数：求和
  - 薪酬：求和
  - 人效：累计营收 ÷ 累计排班人数
  - 千元贡献：(累计营收 ÷ 累计薪酬) × 1000
  - 成本率：(累计薪酬 ÷ 累计营收) × 100%

## API接口

### getDashboardData

获取今日运营仪表盘数据

**参数：**
- `tenantId`: 租户ID（string）

**返回值：**
```typescript
{
  today: {
    revenue: number                      // 当日营收
    rest_count: number                   // 当日排休人数
    efficiency: number                   // 当日人效
    labor_cost: number                   // 当日薪酬
    thousand_yuan_contribution: number   // 当日千元贡献
    cost_ratio: number                   // 当日成本率
    planned_staff_count: number          // 当日排班人数
  }
  accumulated: {
    revenue: number                      // 累计营收
    rest_count: number                   // 累计排休人数
    efficiency: number                   // 累计人效
    labor_cost: number                   // 累计薪酬
    thousand_yuan_contribution: number   // 累计千元贡献
    cost_ratio: number                   // 累计成本率
    planned_staff_count: number          // 累计排班人数
  }
  days_count: number                     // 累计天数
}
```

**示例：**
```typescript
import {getDashboardData} from '@/db/api'

const data = await getDashboardData(tenantId)
console.log('当日营收:', data.today.revenue)
console.log('累计营收:', data.accumulated.revenue)
console.log('累计天数:', data.days_count)
```

## 注意事项

1. **数据依赖**
   - 仪表盘数据依赖于 `schedule_results` 表
   - 需要先完成排班规划，才会有数据展示
   - 如果没有数据，会显示空状态提示

2. **数据更新**
   - 数据会在页面加载时自动获取
   - 可以通过刷新按钮手动刷新数据
   - 从其他页面返回首页时会自动刷新数据

3. **评估标准**
   - 评估标准是基于餐饮行业的一般标准
   - 不同行业可能需要调整评估标准
   - 可以根据实际情况修改评估函数

4. **数据洞察**
   - 需要至少3天的数据才会显示洞察
   - 洞察内容会根据实际数据动态生成
   - 可能同时显示多条洞察信息
