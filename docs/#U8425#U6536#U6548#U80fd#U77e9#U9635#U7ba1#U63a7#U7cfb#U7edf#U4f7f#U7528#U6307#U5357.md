# 营收-效能矩阵管控系统使用指南

## 系统概述

营收-效能矩阵管控系统是一套基于营收区间的智能排班和效能管理工具，帮助餐饮企业实现科学化、标准化的人力成本管控。

### 核心理念

根据不同的营收水平，采用不同的效能标准和管理策略：
- **低营收区**：严控成本，生存第一
- **正常营收区**：精益运营，效率为王
- **高营收区**：保障效能，利润冲刺

### 管理流程

```
排班规划 → 营业调整 → 营业复盘
   ↓          ↓          ↓
预估营收   午市调整   实际评估
   ↓          ↓          ↓
计算工时   动态切换   效能评级
```

## 功能模块

### 1. 效能标准配置

**功能说明**：配置不同营收区间的效能标准和管理口令

**使用步骤**：
1. 进入"管理中心" → "效能标准配置"
2. 选择配置级别：
   - 租户默认配置：适用于所有店铺
   - 店铺独立配置：针对特定店铺
3. 配置三个营收区间：
   - **低营收区**：设置上限、效能标准、管理口令
   - **正常营收区**：设置下限、上限、效能标准、管理口令
   - **高营收区**：设置下限、效能标准、管理口令
4. 点击"保存配置"

**默认配置示例**：
- 低营收区：< ¥10,000，标准700元/人/日
- 正常营收区：¥10,000 ~ ¥18,000，标准850元/人/日
- 高营收区：≥ ¥18,000，标准1000元/人/日

**注意事项**：
- 店铺独立配置优先于租户默认配置
- 营收区间不能有重叠
- 效能标准应根据实际情况合理设置

### 2. 排班规划

**功能说明**：基于预估营收自动计算目标工时，指导排班安排

**使用步骤**：
1. 进入"管理中心" → "排班规划"
2. 选择店铺和日期
3. 输入预估营收
4. 系统自动显示：
   - 所属营收区间
   - 适用的效能标准
   - 目标工时（预估营收 ÷ 效能标准）
   - 管理口令
5. 根据目标工时安排排班
6. 点击"保存规划"

**排班建议**：
- 排班总工时应≤目标工时
- 优先安排核心岗位
- 预留一定弹性空间

**示例**：
```
预估营收：¥15,000
所属区间：正常营收区
效能标准：850元/人/日
目标工时：17.6小时
管理口令：精益运营，效率为王
```

### 3. 营业调整

**功能说明**：午市后根据实际情况动态调整排班

**使用步骤**：
1. 进入"管理中心" → "营业调整"
2. 选择店铺和日期
3. 查看早班规划数据
4. 输入午市后的全天营收预估
5. 系统自动显示：
   - 新的营收区间（如有变化）
   - 新的效能标准
   - 新的目标工时
   - 标准切换提醒
6. 输入调整后的工时
7. 查看调整建议
8. 点击"保存调整"

**调整场景**：
- **营收超预期**：可能切换到更高区间，增加人手
- **营收低于预期**：可能切换到更低区间，减少人手
- **营收符合预期**：保持原有安排

**示例**：
```
早班预估：¥15,000（正常区）
午市后预估：¥20,000（高营收区）
标准切换：850 → 1000元/人/日
新目标工时：20小时
建议：可适当增加晚市人手
```

### 4. 营业复盘

**功能说明**：营业结束后评估实际效能表现

**使用步骤**：
1. 进入"管理中心" → "营业复盘"
2. 选择店铺和日期
3. 查看规划数据回顾
4. 输入实际营收和实际工时
5. 系统自动计算：
   - 人均营收（实际营收 ÷ 实际工时）
   - 所属营收区间
   - 适用的效能标准
   - 效能评级
6. 填写复盘备注
7. 点击"保存复盘"

**评级标准**：
- **优秀**：人均营收 ≥ 效能标准
- **合格**：人均营收 ≥ 效能标准 × 90%
- **未达标**：人均营收 < 效能标准 × 90%

**示例**：
```
实际营收：¥18,500
实际工时：20小时
人均营收：925元/人/日
所属区间：高营收区
效能标准：1000元/人/日
评级：合格（92.5%）
```

### 5. 排班速查表

**功能说明**：快速查询不同营收对应的目标工时

**使用步骤**：
1. 进入"管理中心" → "排班速查表"
2. 选择店铺
3. 查看速查表：
   - 预估营收
   - 所属区间
   - 效能标准
   - 目标工时
4. 查看管理口令

**使用场景**：
- 快速排班决策
- 培训新员工
- 制定排班标准

## 最佳实践

### 1. 标准配置建议

**初期设置**：
- 基于历史数据分析营收分布
- 设置合理的区间划分
- 效能标准应略高于当前水平

**定期调整**：
- 每季度回顾一次配置
- 根据实际表现调整标准
- 考虑季节性因素

### 2. 排班规划技巧

**预估营收**：
- 参考历史同期数据
- 考虑节假日、天气等因素
- 预留10-15%的弹性空间

**工时分配**：
- 核心岗位优先保障
- 高峰时段适当增加
- 低峰时段灵活调整

### 3. 营业调整要点

**调整时机**：
- 午市结束后（约14:00）
- 晚市开始前（约17:00）

**调整原则**：
- 及时响应，快速决策
- 优先调整兼职人员
- 保持核心团队稳定

### 4. 复盘改进方法

**数据分析**：
- 对比预估与实际
- 分析偏差原因
- 总结经验教训

**持续改进**：
- 优化预估方法
- 调整排班策略
- 提升团队效能

## 常见问题

### Q1: 如何设置合理的效能标准？

**A**: 建议步骤：
1. 统计过去3个月的营收和工时数据
2. 计算平均人均营收
3. 按营收区间分别计算
4. 在平均值基础上提高5-10%作为标准

### Q2: 营收区间如何划分？

**A**: 划分原则：
- 低营收区：约占营业天数的20-30%
- 正常营收区：约占营业天数的50-60%
- 高营收区：约占营业天数的10-20%

### Q3: 预估营收总是不准怎么办？

**A**: 改进方法：
- 建立预估模型（历史数据+影响因素）
- 记录预估偏差，分析原因
- 逐步提高预估准确度
- 保持适当的弹性空间

### Q4: 效能评级总是未达标怎么办？

**A**: 分析方向：
- 效能标准是否过高
- 排班是否过于宽松
- 员工效率是否需要提升
- 营收预估是否过于乐观

### Q5: 多店铺如何管理？

**A**: 管理策略：
- 租户级别设置统一标准
- 特殊店铺单独配置
- 定期对比各店表现
- 分享最佳实践

## 数据统计与分析

### 关键指标

1. **预估准确率**：实际营收 / 预估营收
2. **工时控制率**：实际工时 / 目标工时
3. **效能达标率**：达标天数 / 总营业天数
4. **优秀率**：优秀天数 / 总营业天数

### 分析维度

- 按时间：日、周、月、季度
- 按店铺：各店对比分析
- 按区间：不同营收区间表现
- 按员工：个人效能分析
