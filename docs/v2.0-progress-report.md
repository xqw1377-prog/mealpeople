## 🎯 关键技术点

### 排休规则配置页面

1. **不可排休时间选择器**
   ```typescript
   // 日期类型选择
   type: 'single' | 'range'
   
   // 单个日期
   { type: 'single', date: '2025-01-01', reason: '元旦' }
   
   // 日期范围
   { type: 'range', start_date: '2025-02-01', end_date: '2025-02-07', reason: '春节' }
   ```

2. **条件显示逻辑**
   ```typescript
   // 存休配置
   {allow_rest_accumulation && (
     <Input label="最大存休天数" />
   )}
   
   // 连休配置
   {allow_consecutive_rest && (
     <Input label="最多连休天数" />
   )}
   ```

3. **适用员工选择**
   ```typescript
   // 空数组表示适用所有员工
   applicable_employees: []
   
   // 指定员工ID列表
   applicable_employees: ['emp-1', 'emp-2']
   ```

### 最低营收岗位配置

1. **岗位配置数据结构**
   ```typescript
   positions: [
     { position_name: '店长', required_count: 1 },
     { position_name: '服务员', required_count: 3 },
     { position_name: '厨师', required_count: 2 }
   ]
   ```

### 历史营收数据导入

1. **Excel模板格式**
   ```
   | 日期       | 营收金额 | 客流量 | 员工数 | 工时  | 人力成本 | 备注 |
   |-----------|---------|--------|--------|-------|---------|------|
   | 2025-01-01| 50000   | 200    | 8      | 64    | 4800    |      |
   ```

2. **数据验证**
   ```typescript
   // 日期格式验证
   const isValidDate = (dateStr: string) => {
     return /^\d{4}-\d{2}-\d{2}$/.test(dateStr)
   }
   
   // 数值范围验证
   const isValidAmount = (amount: number) => {
     return amount >= 0 && amount <= 1000000
   }
   ```
