## 二、代码下载方式

### 2.1 通过平台界面下载

如果您在秒哒平台上，可以通过以下方式下载代码：

1. **导出项目**
   - 点击项目设置
   - 选择"导出项目"
   - 下载完整项目代码包

2. **Git克隆**（如果项目已关联Git仓库）
   - 获取Git仓库地址
   - 使用`git clone`命令克隆代码

### 2.2 本地开发环境设置

下载代码后，在本地环境中：

```bash
# 1. 安装依赖
pnpm install

# 2. 配置环境变量
# 复制.env.example为.env，填写Supabase配置

# 3. 启动开发服务器
# 微信小程序
pnpm run dev:weapp

# H5
pnpm run dev:h5

# 4. 构建生产版本
pnpm run build:weapp
```

## 四、环境变量配置

### 4.1 必需的环境变量

创建`.env`文件，填写以下配置：

```env
# Supabase配置
TARO_APP_SUPABASE_URL=your_supabase_url
TARO_APP_SUPABASE_ANON_KEY=your_supabase_anon_key

# 应用配置
TARO_APP_NAME=餐时间日人力成本管控助手
TARO_APP_VERSION=3.17.0
```

### 4.2 获取Supabase配置

1. 登录Supabase控制台
2. 选择您的项目
3. 进入Settings > API
4. 复制Project URL和anon public key

## 五、常见问题

### 5.1 下载失败的可能原因

1. **网络问题**
   - 检查网络连接
   - 尝试使用VPN或更换网络

2. **权限问题**
   - 确认您有项目访问权限
   - 联系项目管理员授权

3. **浏览器问题**
   - 清除浏览器缓存
   - 尝试使用其他浏览器
   - 检查浏览器下载设置

4. **文件大小问题**
   - 项目包含node_modules可能较大
   - 确保有足够的磁盘空间
   - 尝试分批下载

### 5.2 构建失败的可能原因

1. **依赖安装失败**
   ```bash
   # 清除缓存重新安装
   rm -rf node_modules
   rm pnpm-lock.yaml
   pnpm install
   ```

2. **环境变量未配置**
   - 检查`.env`文件是否存在
   - 检查环境变量是否正确

3. **Node.js版本问题**
   - 推荐使用Node.js 18+
   - 使用nvm切换Node版本

4. **端口占用**
   ```bash
   # 检查端口占用
   lsof -i :10086  # 微信小程序端口
   lsof -i :10087  # H5端口
   ```
