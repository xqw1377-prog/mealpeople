## 常见问题

### 问题1：页面加载缓慢

**症状**：
- 页面打开很慢
- 数据加载时间长
- 界面卡顿

**可能原因**：
1. 网络连接不稳定
2. 数据量过大
3. 服务器响应慢

**解决方案**：

1. **检查网络连接**
   ```bash
   # 测试网络速度
   ping supabase.co
   ```

2. **清除缓存**
   - 小程序：长按小程序图标 → 删除 → 重新打开
   - H5：清除浏览器缓存

3. **减少数据范围**
   - 缩短时间范围（如从90天改为30天）
   - 选择单个店铺而不是全部店铺

4. **联系技术支持**
   - 如果问题持续，请联系技术支持

### 问题2：数据不显示

**症状**：
- 页面空白
- 显示"暂无数据"
- 数据加载失败

**可能原因**：
1. 没有历史数据
2. 数据库连接失败
3. 权限不足

**解决方案**：

1. **检查是否有数据**
   - 确认已录入历史数据
   - 检查数据时间范围

2. **检查权限**
   - 确认已登录
   - 确认有访问权限
   - 确认租户选择正确

3. **刷新页面**
   - 下拉刷新
   - 重新进入页面

4. **查看错误信息**
   - 打开开发者工具
   - 查看控制台错误
   - 记录错误信息

### 问题3：操作失败

**症状**：
- 点击按钮无反应
- 提交数据失败
- 显示错误提示

**可能原因**：
1. 输入数据不合法
2. 网络请求失败
3. 服务器错误

**解决方案**：

1. **检查输入数据**
   - 确认所有必填项已填写
   - 确认数据格式正确
   - 确认数值在合理范围内

2. **重试操作**
   - 等待几秒后重试
   - 检查网络连接
   - 刷新页面后重试

3. **查看错误提示**
   - 仔细阅读错误信息
   - 根据提示修正
   - 记录错误代码

## 预测功能问题

### 问题1：预测结果不合理

**症状**：
- 预测值过高或过低
- 预测值与实际差距大
- 置信度很低

**可能原因**：
1. 历史数据不足
2. 影响因子设置不当
3. 数据异常

**解决方案**：

1. **检查历史数据**
   ```typescript
   // 确保至少有3个月的历史数据
   // 检查数据是否连续
   // 检查是否有异常值
   ```

2. **调整影响因子**
   - 检查影响因子的影响值是否合理
   - 删除不相关的因子
   - 添加遗漏的重要因子

3. **排除异常数据**
   - 检查是否有异常高或低的营收
   - 考虑特殊情况（如装修、停业）
   - 标记或排除异常数据

4. **逐步优化**
   - 从简单场景开始
   - 逐步添加影响因子
   - 对比预测和实际
   - 持续调整优化

### 问题2：影响因子不生效

**症状**：
- 添加了影响因子但预测结果没变化
- 因子显示但不起作用

**可能原因**：
1. 因子生效日期不对
2. 因子已过期
3. 影响值太小

**解决方案**：

1. **检查日期设置**
   - 确认生效日期 ≤ 预测日期
   - 确认过期日期 > 预测日期（如果设置了）

2. **检查影响值**
   - 确认影响值不为0
   - 确认影响值在合理范围（-1.0到1.0）

3. **检查置信度**
   - 确认置信度 > 0
   - 置信度太低会减弱影响

### 问题3：无法保存预测记录

**症状**：
- 预测完成但没有保存
- 历史记录中找不到

**可能原因**：
1. 数据库写入失败
2. 权限不足
3. 数据格式错误

**解决方案**：

1. **检查权限**
   - 确认有创建预测记录的权限
   - 确认租户管理员身份

2. **检查数据**
   - 确认所有必填字段都有值
   - 确认数值格式正确

3. **查看错误日志**
   - 打开开发者工具
   - 查看网络请求
   - 记录错误信息

## 排班优化问题

### 问题1：计算结果不合理

**症状**：
- 需要的员工数太多或太少
- 预计成本不准确
- 效能值异常

**可能原因**：
1. 目标营收设置不当
2. 历史人效数据不准确
3. 成本数据有误

**解决方案**：

1. **检查目标营收**
   - 确认目标营收在合理范围
   - 参考历史营收数据
   - 考虑季节性因素

2. **更新人效数据**
   - 确认员工效能数据是最新的
   - 检查是否有异常值
   - 重新计算平均效能

3. **检查成本数据**
   - 确认员工工资数据正确
   - 检查是否包含所有成本
   - 更新成本标准

### 问题2：优化建议不适用

**症状**：
- 建议的排班方案无法执行
- 推荐的休假时间不合适

**可能原因**：
1. 没有考虑特殊情况
2. 约束条件不完整
3. 算法参数需要调整

**解决方案**：

1. **人工调整**
   - 基于系统建议进行人工调整
   - 考虑实际约束条件
   - 记录调整原因

2. **反馈问题**
   - 记录不合理的建议
   - 提供实际情况说明
   - 帮助改进算法

3. **配置约束**
   - 设置最小/最大员工数
   - 设置必须在岗的员工
   - 设置不可排班的时间

## 风险预警问题

### 问题1：误报风险

**症状**：
- 显示风险但实际没问题
- 风险级别不准确

**可能原因**：
1. 阈值设置不当
2. 数据不准确
3. 特殊情况未考虑

**解决方案**：

1. **调整阈值**
   - 根据实际情况调整风险阈值
   - 不同店铺可能需要不同阈值

2. **更新数据**
   - 确保数据是最新的
   - 修正错误数据

3. **标记误报**
   - 将误报标记为"忽略"
   - 记录原因
   - 帮助改进检测算法

### 问题2：漏报风险

**症状**：
- 实际有问题但没有预警
- 风险发现太晚

**可能原因**：
1. 检测规则不完善
2. 数据更新不及时
3. 阈值设置太宽松

**解决方案**：

1. **降低阈值**
   - 适当降低风险阈值
   - 提高检测灵敏度

2. **及时更新数据**
   - 每天更新运营数据
   - 实时同步变更

3. **反馈问题**
   - 报告漏报的风险
   - 提供详细情况
   - 帮助完善检测规则

### 问题3：风险处理无效

**症状**：
- 标记为已解决但仍然显示
- 处理后风险仍然存在

**可能原因**：
1. 根本问题未解决
2. 数据未更新
3. 系统缓存

**解决方案**：

1. **确认问题已解决**
   - 检查实际情况
   - 确认数据已更新

2. **刷新数据**
   - 手动刷新页面
   - 重新检测风险

3. **查看历史记录**
   - 检查处理记录
   - 确认操作已保存

## 数据分析问题

### 问题1：趋势分析不准确

**症状**：
- 趋势线与实际不符
- 预测趋势偏差大

**可能原因**：
1. 数据点太少
2. 数据波动太大
3. 异常值影响

**解决方案**：

1. **增加数据范围**
   - 使用更长的时间范围
   - 至少30天的数据

2. **平滑数据**
   - 使用移动平均
   - 过滤异常值

3. **选择合适的模型**
   - 线性趋势
   - 指数趋势
   - 周期性趋势

### 问题2：异常检测误判

**症状**：
- 正常数据被标记为异常
- 异常数据未被检测

**可能原因**：
1. 检测阈值不当
2. 季节性因素
3. 特殊事件

**解决方案**：

1. **调整检测参数**
   - 调整标准差倍数
   - 考虑季节性

2. **标记已知异常**
   - 标记特殊事件
   - 排除已知原因

3. **人工审核**
   - 定期审核异常检测结果
   - 调整检测规则

## 性能问题

### 问题1：查询速度慢

**症状**：
- 数据加载时间长
- 页面响应慢

**可能原因**：
1. 数据量太大
2. 查询未优化
3. 索引缺失

**解决方案**：

1. **优化查询**
   ```sql
   -- 使用索引字段
   -- 限制返回数量
   -- 使用分页
   ```

2. **减少数据量**
   - 缩短时间范围
   - 使用聚合数据
   - 分批加载

3. **添加索引**
   - 检查常用查询字段
   - 添加必要的索引

### 问题2：内存占用高

**症状**：
- 小程序卡顿
- 浏览器崩溃

**可能原因**：
1. 数据缓存过多
2. 内存泄漏
3. 大数据渲染

**解决方案**：

1. **清理缓存**
   - 定期清理过期缓存
   - 限制缓存大小

2. **优化渲染**
   - 使用虚拟列表
   - 分页显示
   - 懒加载

3. **重启应用**
   - 关闭并重新打开
   - 清除应用数据
