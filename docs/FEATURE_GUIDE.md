# 餐时间日人力成本管控助手 - 功能使用指南

## 📱 应用概述

餐时间日人力成本管控助手是一款基于营收-效能标准的多租户智能办公管理工具，帮助企业管理者实现科学排班和成本控制，支持多店连锁管理和智能化运营决策。

## 🎯 核心功能

### 1. 多租户管理

#### 功能说明
支持多个租户（企业）独立管理，数据完全隔离，每个租户可以管理多个店铺和员工。

#### 使用方法
1. 登录后进入租户选择页面
2. 选择要管理的租户
3. 在"我的"页面可以随时切换租户

#### 权限说明
- **超级管理员**：可以管理所有租户和系统设置
- **租户管理员**：可以管理本租户的所有数据
- **店经理**：可以管理本店铺的数据
- **普通员工**：可以查看和提交排班日志

### 2. 今日运营仪表盘

#### 功能说明
实时展示当日和本月累计的运营数据，帮助管理者快速了解运营状况。

#### 主要指标
- **当日数据**：排班完成数、优秀排班数、延期排班数、参与人数
- **本月累计**：总排班数、优秀排班数、平均评分、完成率
- **智能分析**：自动分析数据并提供改进建议

#### 使用场景
- 每日查看运营情况
- 监控排班完成情况
- 发现异常及时处理

### 3. 排班日志系统

#### 功能说明
记录和管理每次排班的执行情况，支持评分、筛选、统计和排行榜功能。

#### 主要功能
1. **日志管理**
   - 创建排班日志
   - 编辑日志信息
   - 删除日志记录
   
2. **筛选功能**
   - 日期范围筛选（今日/近7天/近30天）
   - 按员工筛选
   - 按店铺筛选
   - 按完成状态筛选

3. **统计分析**
   - 总日志数统计
   - 完成率统计
   - 优秀率统计
   - 平均评分统计

4. **员工排行榜**
   - 按优秀数排序
   - 按平均分排序
   - 显示员工排名

#### 使用场景
- 记录每次排班执行情况
- 评估员工工作表现
- 分析排班质量趋势

### 4. 员工管理

#### 功能说明
管理企业的员工信息，支持正式员工和兼职员工，提供完整的CRUD功能和批量导入。

#### 主要功能
1. **员工列表**
   - 查看所有员工
   - 按店铺筛选
   - 按员工类型筛选（正式/兼职）

2. **员工操作**
   - 添加新员工
   - 编辑员工信息
   - 删除员工

3. **Excel批量导入** ⭐ 新功能
   - 下载Excel模板
   - 填写员工信息
   - 上传Excel文件
   - 批量导入员工
   - 查看导入结果

#### 使用场景
- 新员工入职登记
- 员工信息维护
- 批量导入员工数据

### 5. 店铺管理

#### 功能说明
管理企业的店铺信息，支持多店铺管理。

#### 主要功能
- 添加新店铺
- 编辑店铺信息
- 删除店铺
- 查看店铺详情

#### 使用场景
- 新店开业登记
- 店铺信息维护
- 多店铺统一管理

### 6. 排班管理

#### 功能说明
创建和管理排班计划，支持多种班次类型和高级筛选。

#### 主要功能
1. **排班操作**
   - 创建排班计划
   - 编辑排班信息
   - 删除排班

2. **筛选功能**
   - 按店铺筛选
   - 按班次类型筛选
   - 按日期范围筛选

3. **排班统计**
   - 总排班数
   - 各班次类型统计

#### 使用场景
- 制定排班计划
- 调整排班安排
- 查看排班情况

### 7. 数据分析

#### 功能说明
多维度统计分析运营数据，帮助管理者做出决策。

#### 分析维度
1. **核心指标**
   - 店铺数量
   - 员工数量
   - 排班数量
   - 日志数量

2. **质量指标**
   - 平均评分
   - 优秀率
   - 完成率

3. **店铺统计**
   - 各店铺员工数
   - 各店铺日志数
   - 各店铺优秀数

4. **员工统计**
   - 正式员工数
   - 兼职员工数

#### 使用场景
- 定期数据分析
- 运营决策支持
- 绩效评估

### 8. 成本管控

#### 功能说明
分析人力成本，提供优化建议，帮助控制成本。

#### 主要功能
1. **核心指标**
   - 总营收
   - 人力成本
   - 成本占比
   - 平均效能

2. **人员配置**
   - 正式员工数和成本
   - 兼职员工数和成本
   - 人员配置建议

3. **趋势分析**
   - 成本趋势图
   - 效能趋势图

4. **优化建议**
   - 成本控制建议
   - 人员配置建议
   - 效能提升建议

#### 使用场景
- 成本分析和控制
- 人员配置优化
- 效能提升

### 9. 数据导出 ⭐ 新功能

#### 功能说明
将系统中的各类数据导出为多种格式的文件，便于数据分析和备份。

#### 支持的数据类型
1. **员工数据**：导出所有员工信息
2. **店铺数据**：导出所有店铺信息
3. **排班数据**：导出排班计划
4. **排班日志**：导出日志记录
5. **数据分析报表**：导出统计分析数据
6. **成本管控报表**：导出成本分析数据

#### 支持的导出格式
- **Excel格式** (.xlsx)：适合数据分析
- **PDF格式** (.pdf)：适合打印和存档
- **CSV格式** (.csv)：适合数据交换

#### 使用方法
1. 进入"管理中心"
2. 点击"数据导出"
3. 选择要导出的数据类型
4. 选择导出格式
5. 点击"开始导出"
6. 等待导出完成

#### 使用场景
- 定期数据备份
- 数据分析和报表
- 数据迁移

### 10. 消息通知 ⭐ 新功能

#### 功能说明
接收和管理各类系统通知，及时了解重要信息。

#### 通知类型
1. **排班通知**
   - 新排班分配通知
   - 排班变更通知

2. **排班提醒**
   - 排班开始前提醒
   - 排班即将到期提醒

3. **任务提醒**
   - 待完成任务提醒
   - 任务到期提醒

4. **系统公告**
   - 系统维护通知
   - 系统更新通知

#### 通知管理
- 查看通知列表
- 标记单条为已读
- 删除单条通知
- 全部标记为已读
- 查看未读数量

#### 使用方法
1. 进入"我的"页面
2. 点击"消息通知"
3. 查看通知列表
4. 点击"标记已读"或"删除"按钮

#### 使用场景
- 接收排班通知
- 查看任务提醒
- 了解系统公告

### 11. 系统管理

#### 功能说明
超级管理员专用功能，管理系统用户和权限。

#### 主要功能
- 查看所有用户
- 修改用户角色
- 管理用户权限

#### 使用场景
- 用户权限管理
- 角色分配
- 系统维护

## 💡 使用技巧

### 1. 快速筛选
在排班日志、员工管理、排班管理页面，使用高级筛选功能可以快速找到需要的数据。

### 2. 批量导入
使用Excel批量导入功能可以快速录入大量员工数据，提高工作效率。

### 3. 定期导出
定期使用数据导出功能备份重要数据，防止数据丢失。

### 4. 关注通知
及时查看消息通知，不错过重要的排班和任务提醒。

### 5. 数据分析
定期查看数据分析和成本管控页面，了解运营状况，及时调整策略。
