# 效能标准配置问题调试指南

## 问题描述

效能配置页面显示"保存成功"，但排班规划页面仍显示"未配置效能标准"。

## 调试步骤

### 第1步：清空浏览器缓存

1. 打开浏览器开发者工具（F12）
2. 右键点击刷新按钮，选择"清空缓存并硬性重新加载"
3. 或者在开发者工具的Application标签中，清除所有缓存和存储

### 第2步：打开控制台

1. 打开浏览器开发者工具（F12）
2. 切换到"Console"（控制台）标签
3. 确保没有过滤器，显示所有日志级别（Info, Warning, Error）

### 第3步：测试保存功能

1. **进入效能配置页面**
   - 点击"管理中心" → "效能配置"

2. **选择租户默认配置**
   - 在"选择配置对象"下拉框中，选择"租户默认配置"

3. **填写配置**
   - 低营收区上限：10000
   - 低营收区效能标准：700
   - 低营收区管理格言：任意文字
   - 正常营收区上限：18000
   - 正常营收区效能标准：850
   - 正常营收区管理格言：任意文字
   - 高营收区下限：18000
   - 高营收区效能标准：1000
   - 高营收区管理格言：任意文字

4. **点击"保存配置"按钮**

5. **查看控制台日志**
   - 应该看到以下日志序列：
   ```
   选中的店铺: {id: '', name: '租户默认配置', ...}
   准备保存的配置: {tenant_id: "xxx", store_id: null, ...}
   准备保存效能标准配置: {tenant_id: "xxx", store_id: null, ...}
   查询已存在的配置: null 或 {id: "xxx"}
   插入新配置 或 更新现有配置，ID: xxx
   保存效能标准配置成功: {...}
   保存结果: {...}
   === 验证保存 ===
   getTenantEfficiencyStandard: 查询租户级别配置 {tenantId: "xxx"}
   getTenantEfficiencyStandard: 查询结果 {...}
   验证查询（租户级别）: {...}
   === 验证完成 ===
   ```

6. **重点检查**
   - ✅ `store_id`应该是`null`（不是空字符串）
   - ✅ "保存效能标准配置成功"应该有完整的配置对象
   - ✅ "验证查询（租户级别）"应该返回刚才保存的配置
   - ❌ 如果看到任何错误日志，请记录下来

### 第4步：测试加载功能

1. **进入排班规划页面**
   - 点击底部导航栏的"排班规划"

2. **查看控制台日志**
   - 应该看到以下日志序列：
   ```
   === useEffect触发 ===
   {
     storesLength: X,
     selectedStoreIndex: 0,
     selectedStore: {id: "xxx", name: "xxx", ...},
     currentTenantId: "xxx"
   }
   loadStandard: 开始加载效能标准 {tenantId: "xxx", storeId: "xxx"}
   getStoreEfficiencyStandard: 查询店铺级别配置 {tenantId: "xxx", storeId: "xxx"}
   getStoreEfficiencyStandard: 店铺级别查询结果 null
   getStoreEfficiencyStandard: 店铺无配置，尝试获取租户级别配置
   getTenantEfficiencyStandard: 查询租户级别配置 {tenantId: "xxx"}
   getTenantEfficiencyStandard: 查询结果 {...}
   loadStandard: 加载结果 {...}
   ```

3. **重点检查**
   - ✅ `currentTenantId`应该与保存时的`tenant_id`一致
   - ✅ "getTenantEfficiencyStandard: 查询结果"应该返回配置对象（不是null）
   - ✅ "loadStandard: 加载结果"应该返回配置对象（不是null）
   - ❌ 如果看到"loadStandard: 缺少必要参数"，说明参数有问题
   - ❌ 如果看到"getTenantEfficiencyStandard: 查询结果 null"，说明查询失败

4. **查看页面显示**
   - ✅ 不应该看到黄色的"未配置效能标准"提示框
   - ✅ 应该能够输入预估营收并自动计算目标人数
   - ❌ 如果还是显示"未配置效能标准"，说明`standard`状态没有更新

### 第5步：切换店铺测试

1. **在排班规划页面切换店铺**
   - 点击店铺选择下拉框
   - 选择另一个店铺

2. **查看控制台日志**
   - 应该再次看到`loadStandard`的日志序列
   - 确认每次切换店铺都会重新加载配置

3. **查看页面显示**
   - 确认切换店铺后，配置能够正确加载

## 常见问题分析

### 问题1：保存时`store_id`不是null

**症状**：
```
准备保存的配置: {tenant_id: "xxx", store_id: "", ...}
```

**原因**：`store_id`是空字符串而不是null

**解决方案**：检查`upsertEfficiencyStandard`函数中的清理逻辑

### 问题2：验证查询返回null

**症状**：
```
验证查询（租户级别）: null
```

**原因**：
1. 数据没有真正保存到数据库
2. RLS策略阻止了查询
3. 租户ID不匹配

**解决方案**：
1. 检查"保存效能标准配置成功"的日志，确认返回了配置对象
2. 检查数据库的RLS策略
3. 对比保存和查询时的租户ID

### 问题3：排班规划页面查询返回null

**症状**：
```
getTenantEfficiencyStandard: 查询结果 null
```

**原因**：
1. 租户ID不一致
2. RLS策略阻止了查询
3. 数据库中确实没有数据

**解决方案**：
1. 对比保存时和查询时的租户ID
2. 检查用户是否切换了租户
3. 检查RLS策略

### 问题4：loadStandard缺少必要参数

**症状**：
```
loadStandard: 缺少必要参数 {tenantId: undefined, storeId: undefined}
```

**原因**：
1. `currentTenant`未初始化
2. `stores`数组为空
3. `selectedStoreIndex`超出范围

**解决方案**：
1. 确认用户已登录并选择了租户
2. 确认店铺数据已加载
3. 检查`selectedStoreIndex`的值

### 问题5：查询成功但页面仍显示"未配置效能标准"

**症状**：
- 控制台显示"loadStandard: 加载结果 {...}"
- 但页面仍显示黄色提示框

**原因**：
1. `setStandard`没有被调用
2. React状态更新失败
3. 组件没有重新渲染

**解决方案**：
1. 检查`loadStandard`函数中是否调用了`setStandard(config)`
2. 检查`config`是否为null
3. 尝试刷新页面

## 需要提供的信息

如果问题仍然存在，请提供以下信息：

1. **完整的控制台日志**
   - 从打开效能配置页面开始
   - 到排班规划页面显示"未配置效能标准"为止
   - 包括所有日志，不要省略

2. **租户信息**
   - 租户ID
   - 租户名称

3. **店铺信息**
   - 店铺ID
   - 店铺名称

4. **用户信息**
   - 用户ID
   - 用户角色

5. **浏览器信息**
   - 浏览器类型和版本
   - 操作系统

6. **截图**
   - 效能配置页面的截图
   - 排班规划页面的截图
   - 控制台日志的截图

## 临时解决方案

如果问题无法立即解决，可以尝试以下临时方案：

1. **配置店铺级别的效能标准**
   - 不使用"租户默认配置"
   - 为每个店铺单独配置效能标准

2. **手动输入目标人数**
   - 暂时不依赖自动计算
   - 手动输入计划人数

3. **清除浏览器数据**
   - 清除所有缓存和Cookie
   - 重新登录系统
