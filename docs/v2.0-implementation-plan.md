## 📝 开发规范

### 代码规范
- 使用TypeScript严格模式
- 所有组件使用函数式组件
- 使用React Hooks管理状态
- 遵循Taro组件规范
- 使用Tailwind CSS样式

### 命名规范
- 页面文件：kebab-case（如：min-revenue-config）
- 组件名称：PascalCase（如：MinRevenueConfig）
- 函数名称：camelCase（如：createMinRevenueConfig）
- 常量名称：UPPER_SNAKE_CASE（如：MAX_REVENUE_VALUE）

### 注释规范
- 所有函数添加JSDoc注释
- 复杂逻辑添加行内注释
- 所有接口添加注释说明

### 测试规范
- 每完成一个页面立即测试
- 测试所有功能点
- 测试边界情况
- 测试错误处理
