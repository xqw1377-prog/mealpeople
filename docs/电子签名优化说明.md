## 一、问题诊断

### 1.1 用户反馈
用户反馈：**电子签模板目前不能用**

### 1.2 问题分析

经过全面检查，发现以下问题：

#### 1.2.1 Canvas API兼容性问题
```typescript
// ❌ 旧版实现 - 存在问题
Taro.canvasToTempFilePath({
  canvasId,  // 只传入canvasId，在新版Taro中可能失败
  success: (res) => {
    onSave(res.tempFilePath)
  },
  fail: (error) => {
    console.error('保存签名失败:', error)
  }
})
```

**问题**：
1. 使用旧版Canvas API，不传入canvas实例
2. 没有使用async/await，错误处理不完善
3. Canvas初始化没有延迟，可能DOM未渲染完成
4. 缺少Canvas就绪状态检查

#### 1.2.2 Canvas初始化时机问题
```typescript
// ❌ 旧版实现 - 可能过早初始化
useEffect(() => {
  // 立即初始化，DOM可能未渲染完成
  const query = Taro.createSelectorQuery()
  query.select(`#${canvasId}`)...
}, [])
```

**问题**：
1. 没有延迟初始化
2. 没有检查Canvas是否成功初始化
3. 缺少初始化状态反馈

#### 1.2.3 触摸事件处理问题
```typescript
// ❌ 旧版实现 - 缺少状态检查
const handleTouchStart = (e: any) => {
  if (!contextRef.current) return  // 只检查context
  // 没有检查Canvas是否就绪
  const touch = e.touches[0]
  const {x, y} = touch
  ...
}
```

**问题**：
1. 没有检查Canvas就绪状态
2. 没有preventDefault/stopPropagation
3. 缺少调试日志

## 二、优化方案

### 2.1 Canvas API优化

#### 2.1.1 使用新版Canvas API
```typescript
// ✅ 新版实现 - 传入canvas实例
const handleSave = async () => {
  try {
    Taro.showLoading({title: '保存中...'})

    const {canvas} = contextRef.current

    // 使用新版API，传入canvas实例
    const res = await Taro.canvasToTempFilePath({
      canvas,        // ✅ 传入canvas实例
      fileType: 'png',
      quality: 1
    })

    Taro.hideLoading()

    if (res.tempFilePath) {
      console.log('签名保存成功:', res.tempFilePath)
      onSave(res.tempFilePath)
    } else {
      throw new Error('未获取到图片路径')
    }
  } catch (error) {
    Taro.hideLoading()
    console.error('保存签名失败:', error)
    Taro.showToast({
      title: '保存失败，请重试',
      icon: 'error',
      duration: 2000
    })
  }
}
```

**优化点**：
1. ✅ 传入canvas实例，兼容新版Taro
2. ✅ 使用async/await，错误处理更完善
3. ✅ 添加详细的错误日志
4. ✅ 用户友好的错误提示

### 2.2 Canvas初始化优化

#### 2.2.1 延迟初始化
```typescript
// ✅ 新版实现 - 延迟初始化
const initCanvas = useCallback(() => {
  try {
    const query = Taro.createSelectorQuery()
    query
      .select(`#${canvasId}`)
      .fields({node: true, size: true})
      .exec((res) => {
        if (res && res[0]) {
          const canvas = res[0].node
          const ctx = canvas.getContext('2d')

          if (!ctx) {
            console.error('无法获取Canvas上下文')
            Taro.showToast({
              title: 'Canvas初始化失败',
              icon: 'none'
            })
            return
          }

          // 获取设备像素比
          const dpr = Taro.getSystemInfoSync().pixelRatio || 2
          const width = res[0].width
          const height = res[0].height

          // 设置Canvas实际尺寸（考虑设备像素比）
          canvas.width = width * dpr
          canvas.height = height * dpr

          // 缩放绘图上下文以匹配设备像素比
          ctx.scale(dpr, dpr)

          // 设置画笔样式
          ctx.strokeStyle = '#000000'
          ctx.lineWidth = 3
          ctx.lineCap = 'round'
          ctx.lineJoin = 'round'

          // 填充白色背景
          ctx.fillStyle = '#FFFFFF'
          ctx.fillRect(0, 0, width, height)

          // 保存上下文引用
          contextRef.current = {
            ctx,
            canvas,
            width,
            height,
            dpr
          }

          setCanvasReady(true)  // ✅ 设置就绪状态

          console.log('Canvas初始化成功', {width, height, dpr})
        } else {
          console.error('Canvas节点查询失败')
          Taro.showToast({
            title: 'Canvas初始化失败',
            icon: 'none'
          })
        }
      })
  } catch (error) {
    console.error('Canvas初始化异常:', error)
    Taro.showToast({
      title: 'Canvas初始化异常',
      icon: 'none'
    })
  }
}, [])

useEffect(() => {
  // ✅ 延迟300ms初始化，确保DOM已渲染
  const timer = setTimeout(() => {
    initCanvas()
  }, 300)

  return () => clearTimeout(timer)
}, [initCanvas])
```

**优化点**：
1. ✅ 使用useCallback包装initCanvas
2. ✅ 延迟300ms初始化，确保DOM渲染完成
3. ✅ 添加canvasReady状态
4. ✅ 完善的错误处理和日志
5. ✅ 保存设备像素比信息

#### 2.2.2 Canvas就绪状态管理

### 2.3 触摸事件优化

#### 2.3.1 完善的事件处理
```typescript
// ✅ 新版实现 - 完善的事件处理
const handleTouchStart = (e: any) => {
  if (!contextRef.current || !canvasReady) {
    console.warn('Canvas未就绪')
    return
  }

  e.preventDefault()      // ✅ 阻止默认行为
  e.stopPropagation()     // ✅ 阻止事件冒泡

  const touch = e.touches[0]
  const {x, y} = touch

  lastPointRef.current = {x, y}
  setIsDrawing(true)
  setIsEmpty(false)

  console.log('开始绘制', {x, y})  // ✅ 调试日志
}

const handleTouchMove = (e: any) => {
  if (!isDrawing || !contextRef.current || !lastPointRef.current || !canvasReady) {
    return
  }

  e.preventDefault()      // ✅ 阻止默认行为
  e.stopPropagation()     // ✅ 阻止事件冒泡

  const touch = e.touches[0]
  const {x, y} = touch
  const {ctx} = contextRef.current

  // 绘制线条
  ctx.beginPath()
  ctx.moveTo(lastPointRef.current.x, lastPointRef.current.y)
  ctx.lineTo(x, y)
  ctx.stroke()

  lastPointRef.current = {x, y}
}
```

**优化点**：
1. ✅ 检查Canvas就绪状态
2. ✅ 阻止默认行为和事件冒泡
3. ✅ 添加调试日志
4. ✅ 完善的状态检查

## 六、注意事项

### 6.1 Canvas API注意事项

1. **必须传入canvas实例**
   ```typescript
   // ✅ 正确
   await Taro.canvasToTempFilePath({
     canvas,  // 传入canvas实例
     fileType: 'png',
     quality: 1
   })

   // ❌ 错误（旧版API）
   await Taro.canvasToTempFilePath({
     canvasId,  // 只传入canvasId
   })
   ```

2. **延迟初始化**
   - Canvas初始化必须延迟，确保DOM已渲染
   - 建议延迟300ms以上

3. **设备像素比**
   - 必须考虑设备像素比，否则签名模糊
   - 使用`Taro.getSystemInfoSync().pixelRatio`

### 6.2 状态管理注意事项

1. **Canvas就绪状态**
   - 所有Canvas操作前必须检查`canvasReady`
   - 初始化失败时要有明确提示

2. **签名状态**
   - 使用`isEmpty`状态管理签名是否为空
   - 未签名时禁用保存按钮

### 6.3 错误处理注意事项

1. **完善的错误处理**
   - 所有异步操作都要try-catch
   - 错误要有详细的日志
   - 用户要有友好的提示

2. **调试日志**
   - 关键操作要有console.log
   - 便于问题排查
