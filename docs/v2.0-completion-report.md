## 🎯 核心功能演示

### 1. 智能营收预测
```typescript
// 预测下月营收
const prediction = await revenuePredictionService.predictRevenue(
  tenantId,
  'monthly',
  '2025-12-01'
)

// 结果示例
{
  conservative: 45000,  // 保守预测
  baseline: 50000,      // 基准预测
  optimistic: 55000,    // 乐观预测
  confidence: 0.85      // 置信度85%
}
```

### 2. 反向排班计算
```typescript

{
```
