# 2.0版本快速开始指南

## 概述

本指南帮助开发人员快速了解和使用2.0版本的新功能。

## 环境准备

### 1. 切换到2.0开发分支

```bash
git checkout develop/v2.0
```

### 2. 安装依赖

```bash
pnpm install
```

### 3. 配置环境变量

确保`.env`文件包含以下配置：

```env
# 应用版本
TARO_APP_VERSION=2.0.0-dev

# Supabase配置
TARO_APP_SUPABASE_URL=your_supabase_url
TARO_APP_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 4. 数据库迁移

2.0版本的数据库迁移已经应用，包括：
- 审计日志系统（shared/00_audit_system.sql）
- 2.0版本核心表（v2/01_create_v2_tables.sql）

如果需要重新应用迁移，请联系数据库管理员。

## 核心功能使用

### 1. 智能营收预测

#### 服务模块
```typescript
import { revenuePredictionService } from '@/services/prediction'

// 预测月度营收
const prediction = await revenuePredictionService.predictRevenue(
  tenantId,
  'monthly',
  '2025-12-01',
  storeId
)

// 获取影响因子
const factors = await revenuePredictionService.getImpactFactors(
  tenantId,
  '2025-12-01'
)
```

#### 页面路由
- 营收预测：`/pages/revenue-prediction/index`
- 影响因子管理：`/pages/impact-factors/index`

## 常见问题

### Q1: 如何在1.0和2.0之间切换？

A: 使用Git切换分支：
```bash
# 切换到1.0版本
git checkout master

# 切换到2.0版本
git checkout develop/v2.0
```

### Q2: 2.0版本会影响1.0版本的数据吗？

A: 不会。2.0版本使用独立的数据库表，不会影响1.0版本的数据。审计日志系统会记录所有操作，确保数据安全。

### Q3: 如何添加新的影响因子？

A: 使用影响因子管理页面或调用API：
```typescript
await createImpactFactor({
  tenant_id: tenantId,
  factor_type: 'weather',
  factor_name: '下雨',
  impact_value: -0.15,
  effective_date: '2025-12-01',
  data_source: 'manual'
})
```

### Q4: 如何查看风险预警？

A: 访问风险预警页面（/pages/risk-alerts/index），或调用API：
```typescript
const risks = await riskWarningService.detectAllRisks(tenantId)
```

### Q5: 如何优化排班？

A: 访问排班优化页面（/pages/schedule-optimization/index），输入目标营收和日期，系统会自动计算最优排班方案。
