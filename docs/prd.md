# 餐时间工作旅程系统需求文档（更新版）

## 1. 项目概述

### 1.1 系统定位
餐时间工作旅程系统是一款专为餐饮企业打造的员工全生命周期管理平台，涵盖面试、入职、在职、离职全流程管理，遵循〔容易学、容易做、容易管〕的核心设计原则，通过小程序端+WEB端协同，实现从候选人到正式员工的全程数字化管理。

### 1.2 品牌命名
- 系统名称：餐时间工作旅程系统
- 英文名称：MealTime Work Journey System
- 简称：餐时间系统

### 1.3 核心价值
- 容易学：界面简洁直观，操作流程清晰，新用户快速上手
- 容易做：流程标准化、自动化，减少人工操作，提升效率
- 容易管：数据可视化、流程可追溯，管理决策有据可依
- 全流程管理：覆盖面试、入职、在职、离职全生命周期
- 双线架构：管理操作线（WEB端）与员工操作线（小程序端）并行

## 3. 核心功能模块

### 3.1 【核心模块】面试流程（WEB端+小程序端）

#### 3.1.1 流程总览

**核心设计原则**：容易学、容易做、容易管

**流程总览**：
```
HR发送面试邀约（链接或二维码） → 候选人通过链接/扫码进入小程序 → 候选人填写面试信息 → 形成面试流程文档 → 面试官在面试文档上填写评估 → 确认复试时间 → 面试流程流转给复试人 → 复试评估 → 此流程可重复多轮 → 复试完成评估后转入职办理
```

#### 3.1.2 管理端操作（WEB端）

##### 3.1.2.1 发送面试邀约

**功能流程**：
```
创建面试邀约 → 填写候选人信息 → 设置面试时间地点 → 选择面试官 → 生成面试邀约链接或二维码 → 发送给候选人（短信、邮件或微信）
```

**字段设计**：
- 候选人信息：
  + 姓名：文本输入框
  + 手机号：文本输入框（自动校验格式）
  + 应聘岗位：下拉选择框
  + 简历附件：支持上传PDF、Word等格式简历
- 面试时间：
  + 面试日期：日期选择器
  + 开始时间：时间选择器
  + 结束时间：时间选择器（默认1小时）
- 面试地点：
  + 面试地点类型：现场面试、视频面试、电话面试
  + 门店地址：下拉选择框（如为现场面试）
  + 视频会议链接：文本输入框（如为视频面试）
  + 联系电话：文本输入框（如为电话面试）
- 面试官：
  + 面试官姓名：下拉选择框（支持多选）
  + 面试官职位：自动显示
  + 面试官联系方式：自动显示
- 面试轮次：
  + 自动标识为第X轮面试（初始为第1轮）
- 面试邀约链接/二维码：
  + 系统自动生成唯一面试邀约链接
  + 系统自动生成面试邀约二维码
  + 支持复制链接或下载二维码
- 发送方式：
  + 短信发送：勾选后系统自动发送短信给候选人\n  + 邮件发送：勾选后系统自动发送邮件给候选人
  + 微信发送：复制链接或二维码手动发送给候选人

**页面交互**：
- 批量导入候选人：支持Excel批量导入候选人信息
- 面试时间冲突提示：当面试官在同一时间段已有面试安排时，系统自动提示冲突
- 面试地点地图展示：选择门店地址后自动显示地图位置
- 邀约预览：发送前可预览面试邀约内容
- 一键发送：点击发送按钮，系统自动发送面试邀约给候选人和面试官

**通知机制**：
- 候选人通知：发送面试邀约后，候选人立即收到短信或邮件通知
- 面试官通知：发送面试邀约后，面试官立即收到系统通知
- 面试提醒：面试前1天、前1小时分别推送提醒通知给候选人和面试官

##### 3.1.2.2 面试流程文档管理

**功能流程**：
```
候选人填写面试信息后自动生成面试流程文档 → HR查看面试流程文档 → 面试官在文档上填写面试评估 → 确认是否进入复试 → 如需复试则安排复试并流转给复试人 → 复试人在文档上填写复试评估 → 此流程可重复多轮 → 复试完成后确认是否转入职办理
```

**字段设计**：
- 面试流程文档结构：
  + 候选人基本信息：姓名、手机号、应聘岗位、简历附件
  + 候选人填写信息：教育背景、工作经历、自我介绍、期望薪资、到岗时间等
  + 面试轮次记录：
    - 第X轮面试
    - 面试时间：日期、开始时间、结束时间
    - 面试地点：门店地址或视频会议链接
    - 面试官：姓名、职位
    - 面试评估：
      * 评估维度（5分制评分）：专业能力、沟通能力、团队协作、学习能力、形象气质
      * 面试表现记录：文本框记录面试过程中的关键表现
      * 优势与不足：总结候选人的突出优点和需改进之处
      * 面试结论：通过（进入下一轮）、不通过（淘汰）、待定（需进一步讨论）
      * 面试官签名：电子签名确认
    - 复试安排：
      * 复试时间：日期、开始时间、结束时间
      * 复试地点：门店地址或视频会议链接
      * 复试面试官：姓名、职位
      * 复试重点：需重点考察的方向
  + 综合评估：
    - 各轮次评分汇总：自动计算平均分
    - 优势总结：候选人的突出优点（3-5条）
    - 风险提示：候选人可能存在的问题或风险（如有）
    - 薪资建议：综合各轮次意见给出的薪资建议范围
    - HR意见：HR对候选人的综合判断和建议
  + 转入职办理：
    - 是否转入职：是、否
    - 如选择是，则进入入职流程

**页面交互**：
- 面试流程文档列表：以列表形式展示所有面试流程文档
- 文档状态标识：待填写、面试中、复试中、已完成、已淘汰、已转入职
- 一键查看：点击文档可查看完整面试流程信息
- 流转操作：点击流转按钮，选择复试面试官，系统自动发送通知
- 评分可视化：以雷达图形式展示各轮次评分对比
- 转入职操作：点击转入职按钮，系统自动生成入职流程文档

**通知机制**：
- 面试评估提醒：面试结束后2小时内未提交评估，系统自动提醒面试官
- 流转通知：面试流程流转给复试人后，系统自动通知复试人
- 转入职通知：面试流程转入职办理后，系统自动通知HR和候选人

**数据统计**：
- 面试通过率：统计各岗位、各轮次的面试通过率
- 面试周期：统计从面试邀约到转入职的平均周期
- 面试官评估效率：统计各面试官的评估提交及时率

##### 3.1.2.3 Agent智能协助

**功能流程**：
```
候选人或面试官在面试流程中发起咨询 → Agent智能识别问题类型 → 提供相关岗位信息、面试流程说明、技术支持等即时回答 → 记录咨询日志
```

**支持场景**：
- 候选人咨询：面试时间确认、面试地点导航、面试准备事项、岗位职责说明
- 面试官咨询：面试流程操作、评估标准查询、候选人信息查询、面试安排调整
- 系统技术支持：链接无法打开、二维码扫描异常、信息填写问题

**Agent响应能力**：
- 自动识别问题意图：基于关键词匹配和语义理解
- 智能知识库检索：连接系统内部知识库和文档
- 多轮对话支持：保持上下文理解进行连续对话
- 超出范围提醒：当问题超出设定范围时提示转人工处理

**咨询记录管理**：
- 自动记录咨询时间、咨询内容、Agent回答
- 支持人工查看和管理咨询日志
- 提供咨询服务质量统计分析
