## 🎨 技术特点

### 前端技术
- **框架**：Taro 3.x + React 18
- **语言**：TypeScript
- **样式**：Tailwind CSS
- **状态管理**：React Hooks + Context API

## 🗄️ 数据库结构

### 核心表
1. **tenants** - 租户表
   - 租户基本信息
   - 租户配置

2. **profiles** - 用户表
   - 用户基本信息
   - 用户角色
   - 租户关联

3. **stores** - 店铺表
   - 店铺基本信息
   - 租户关联

4. **employees** - 员工表
   - 员工基本信息
   - 员工类型（正式/兼职）
   - 店铺关联
   - 租户关联

5. **schedules** - 排班表
   - 排班计划
   - 班次类型
   - 员工关联
   - 店铺关联
   - 租户关联

6. **schedule_logs** - 排班日志表
   - 日志记录
   - 评分信息
   - 完成状态
   - 排班关联
   - 租户关联

7. **operations_data** - 运营数据表
   - 运营指标
   - 店铺关联
   - 租户关联

8. **cost_data** - 成本数据表
   - 成本信息
   - 店铺关联
   - 租户关联

### 权限控制
- 所有表启用Row Level Security (RLS)
- 基于租户ID的数据隔离
- 基于用户角色的权限控制
- 超级管理员拥有全部权限
