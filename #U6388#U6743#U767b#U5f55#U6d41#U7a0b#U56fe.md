## 🔐 授权验证的核心逻辑

### 关键代码片段

#### 1. 超级管理员创建租户

```typescript
// Edge Function: super-admin-create-tenant

// 验证超级管理员权限
const { data: profile } = await supabase
  .from('profiles')
  .select('role')
  .eq('id', user.id)
  .single()

if (profile.role !== 'super_admin') {
  throw new Error('权限不足：只有超级管理员可以创建租户')
}

// 创建租户，存储 admin_phone 🔑
const { data: tenant } = await supabase
  .from('tenants')
  .insert({
    name: tenantName,
    admin_phone: cleanPhone,  // 🔑 存储授权凭证
    industry: industry,
    package_type: packageType,
    status: 'active'
  })
  .select()
  .single()
```

#### 2. 租户管理员登录验证

```typescript
// Edge Function: tenant-admin-login

// 查询该电话号码是否是某个租户的管理员 🔑
const { data: tenant } = await supabase
  .from('tenants')
  .select('*')
  .eq('admin_phone', cleanPhone)  // 🔑 关键验证点
  .eq('status', 'active')
  .maybeSingle()

if (!tenant) {
  // 电话号码未授权 ❌
  throw new Error('该手机号未授权，请联系超级管理员')
}

// 找到租户，创建用户 profile ✅
const { error } = await supabase
  .from('profiles')
  .insert({
    id: user.id,
    tenant_id: tenant.id,        // 🔗 关联到租户
    role: 'tenant_admin',        // 👑 设置为租户管理员
    phone: cleanPhone
  })
```

## ✅ 总结确认

### 问题：租户管理员首次登录是否依赖超级管理员创建租户时录入的电话号码？

**答案：是的！完全正确！**

### 核心机制

1. **唯一授权凭证**：
   - 超级管理员录入的 `admin_phone` 是唯一的授权凭证 🔑
   - 租户管理员必须使用该电话号码登录

2. **验证流程**：
   - 输入电话号码 → 获取验证码 → 系统验证 `admin_phone` 是否匹配
   - 匹配成功 → 自动创建租户管理员账号 ✅
   - 匹配失败 → 提示未授权 ❌

3. **安全保障**：
   - 验证码验证（Supabase Auth）
   - 电话号码匹配验证（admin_phone）
   - 租户状态验证（status = active）

4. **自动化**：
   - 首次登录时自动创建 profile
   - 自动设置为 `tenant_admin` 角色
   - 自动关联到对应的租户
