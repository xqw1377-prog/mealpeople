### 🎯 设计理念

系统遵循"**易学、易做、易管**"的三易思维，为不同角色提供清晰的使用流程和引导。

### 📋 角色体系

系统定义了5个核心角色，每个角色有不同的权限和工作流程：

#### 1️⃣ 超级管理员（super_admin）
**职责**：平台级管理
- 管理所有租户
- 审核租户申请
- 系统全局配置

**快速开始流程**：
1. 管理租户 → 查看和管理所有租户
2. 审核申请 → 处理租户申请和审核

#### 2️⃣ 租户管理员（tenant_admin）
**职责**：企业级配置和管理
- 配置租户信息
- 管理门店和岗位
- 管理员工和权限
- 管理Agent（区域经理/督导）
- 查看数据统计

**快速开始流程（5步配置向导）**：
1. **第1步：完善租户信息** → 设置企业名称、行业类型等基本信息
2. **第2步：添加门店** → 创建门店，设置店经理
3. **第3步：配置岗位** → 设置岗位信息和职级体系
4. **第4步：导入员工** → 批量导入或手动添加员工
5. **第5步：完成配置** → 查看配置中心，完善其他设置

#### 3️⃣ Agent（区域经理/督导）
**职责**：区域级管理
- 管理多个门店
- 查看门店运营数据
- 管理门店员工
- 查看排班和考勤
- 成本分析

**快速开始流程（3步快速上手）**：
1. **查看我的门店** → 了解分配给我的门店
2. **员工管理** → 查看和管理门店员工
3. **数据分析** → 查看运营数据和成本分析

#### 4️⃣ 店经理（store_manager）
**职责**：门店级管理
- 查看门店员工
- 管理排班
- 查看考勤
- 处理日常事务

**快速开始流程（3步快速上手）**：
1. **查看员工** → 了解门店员工信息
2. **排班管理** → 创建和管理员工排班
3. **考勤管理** → 查看员工考勤记录

#### 5️⃣ 普通员工（employee）
**职责**：日常工作
- 查看个人信息
- 查看排班
- 记录工作日志（支持拍照/视频、语音转文字、分类管理）
- 查看工资

**快速开始流程（3步日常使用）**：
1. **完善个人信息** → 查看和更新个人资料
2. **查看我的班次** → 了解本周排班安排

## 数据库架构

### 核心表结构

1. **tenants** - 租户表
   - 租户基本信息、行业类型、套餐类型
   - 店铺数量、员工数量统计

2. **tenant_applications** - 租户申请表
   - 申请人信息、租户信息
   - 申请状态（待审核/已批准/已拒绝）
   - 审核信息（审核人、审核时间、拒绝原因）

3. **profiles** - 用户表
   - 用户信息、角色权限
   - 关联租户ID（支持微信ID）

4. **stores** - 店铺表
   - 店铺信息、店经理
   - 关联租户ID

5. **employees** - 员工表
   - 员工信息、员工类型（正式/兼职）
   - 薪酬信息（月薪）、工时配置（每日工作小时数）
   - 关联租户ID和店铺ID

6. **schedules** - 排班表
   - 排班计划、班次类型
   - 关联租户ID、店铺ID、员工ID

7. **schedule_logs** - 排班日志表
   - 排班执行记录、完成状态、评分
   - 关联排班ID、员工ID、店铺ID

8. **operations_data** - 运营数据表
   - 每日运营数据统计
   - 排班完成率、优秀率、延期率

9. **cost_data** - 成本数据表
   - 营收、人力成本、成本占比
   - 员工数量、平均效能

10. **efficiency_standards** - 效能标准配置表
   - 支持租户级别和店铺级别配置
   - 三个营收区间配置（低/正常/高）
   - 每个区间的效能标准和管理口令

10. **daily_operations** - 每日运营记录表
    - 排班规划阶段（预估营收、计划正式工人数、计划兼职工时）
    - 营业中调整阶段（午市后预估、调整后正式工人数、调整后兼职工时）
    - 营业后复盘阶段（实际营收、实际正式工人数、实际兼职工时、人均营收、效能评级）

11. **tenant_settings** - 租户配置表
    - 品牌信息（品牌名称、Logo、描述）
    - 行业类型、联系信息
    - 默认工作时长配置

12. **invitation_codes** - 邀请码表
    - 邀请码信息、角色、有效期
    - 使用次数限制和已使用次数
    - 关联租户ID和创建人

13. **invitation_code_uses** - 邀请码使用记录表
    - 记录邀请码的使用历史
    - 关联邀请码ID和用户ID

### 权限体系

- **超级管理员** (super_admin)：平台级管理，可访问所有租户数据
- **租户管理员** (tenant_admin)：租户级管理，只能访问本租户数据
- **店经理** (store_manager)：店级管理，只能访问本店数据
- **普通员工** (employee)：执行级，只能访问自己的数据
